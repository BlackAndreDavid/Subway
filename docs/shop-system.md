# 经营窗口

仅通过到店顾客买卖，删除系统商品清单、每日补货及仓库直接售出。仓库仍支持格子整理和资源入库。开店消耗一天，同一轮交易或查看仓库不再扣天；离开再开店开始新一轮。

顾客出售水、电、食物、药物、主动道具和模块，购买需求还包括材料和家具。每次交易一件，数量和电量明示；缺货或余额不足保留当前顾客。报价、外貌由日期/站点/顾客序号确定，不随整理仓库改变。成交或婉拒后才推进顾客序号，存档失败完整回滚；旧报价不能再次结算。旧存档可读取，废弃的 `market_stock` 字段自动移除。

`scenes/shop/shop.tscn` 管理报价和操作，`scenes/shop/customer_window.tscn` 封装人物呈现。顾客用0.8秒走近、0.65秒离开，平滑过渡：尺寸38%→100%，不透明度12%→100%，亮度30%→100%；远处更小、更透明、更暗。离开反向过渡，旧人物消失后换下一位。来去期间成交/婉拒不可点击，查看仓库时暂停动画。按钮仅保留“成交”“婉拒”“仓库”“结束营业”。

四位顾客：维修员、医疗信使、拾荒者、种植员。保存风格提示词和每人两份候选，选择B图集，透明裁切、统一脚底与比例，再按连通区域中间色平涂并映射共享32色。四张PNG通过稳定ID `shop/customers/0..3` 调用。

验证：`tests/shop_checks.gd` 覆盖交易双方、缺货/缺电、旧存档、重复点击、旧报价、保存回滚及日耗；`tests/native_shop_checks.gd` 原生渲染四位顾客远处/近处/离开画面，验证窗口尺寸与画面变化，已加入CI。截图 `shop_customer_0..3.png` 及对应 `_far`、`_leaving` 版本。
