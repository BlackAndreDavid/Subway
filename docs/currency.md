# 水晶货币

水晶作为金币，用于经营买卖、顾客预算及战斗商店。电量不再兼作货币，保留每日补给、地铁行程、战斗过门及电池转换用途。新档水晶余额为0；旧档缺少水晶字段时补0，不把既有电量折算或扣除。余额为非负整数，独立显示在基地/地图/经营及战斗HUD，结算时保存。

普通战斗掉落表原货币分支产生水晶，拾取数值为 `round(8×所在区域丰富度)`，至少1。靠近128像素内自动吸附，18像素内拾取，不占任何背包格；满包也能获取，不会补充账户电量或本层电量。旧掉落标签`credits`保持可读，结算到水晶；新标签为`crystal`。物品目录和占格表不包含水晶。

水晶图标复用风格提示词生成双候选，选B后透明裁切、缩放、连通区域中间色精简及共享32色映射；原始候选和源图保留。稳定美术ID`credits`不变，当前内容为三簇薄荷色晶体。

批量交易按整批总价检查付款方余额，确认才一次扣款/入账；失败完全回滚。经营出售获得水晶，购买消耗水晶，顾客预算作相反变动。战斗商店同样支付水晶。持有水晶和货币掉落不受实物背包容量影响。
