# 后续任务：风险回报与区域物资

顺序：先完成并验证像素 PNG 素材与上海地铁主地图，再实施以下数值和标签任务。不得把研究数据或素材占位当成已完成的掉落规则。

- [ ] 建立可追溯的区域经济参考表：工业产值、商业零售、枢纽功能；明确统计年份、区域口径、来源及缺失值。
- [ ] 将区域经济强度映射为游戏物资丰富度；不宣称区域数据代表单站经济产出。
- [ ] 辐射度与风险、物资数量/价值/高阶概率保持正相关；增加确定性和统计测试。
- [ ] 不同区域独立产出池、常见资源权重和专属物资白名单；其他区域绝不掉落专属物资。
- [ ] 站点界面显示丰富度、常见物资和专属物资；游戏辐射与客流数值明确为虚构数值。
- [ ] 验证可玩性与风险回报，并在素材提交后独立提交。
