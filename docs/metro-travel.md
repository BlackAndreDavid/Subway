# 地铁按天移动

沿真实线路图计算主要站点之间的最短路径，每4段连线计1天，向上取整。换乘不另加天数；不同站点最少1天，当前站点0天。公式位于 `Game.TRAVEL_HOPS_PER_DAY`。

每经过一天消耗2水、2食物、5电量，与基地日耗统一，不再叠加原先按路段扣的电费。例如1–4段耗1天及2水/2食物/5电，5–8段耗2天及4水/4食物/10电。“前往”按钮上方固定显示天数和三项总消耗，不随站点详情滚动，资源不足时“前往”禁用。

出发前检查整段行程的全部补给。成功抵达后一次性结算日期、站点、资源、日报和当天顾客队列并保存。资源不足、当前站点、无效目的地、探索中或保存失败均不产生部分扣费或部分移动。

`tests/travel_checks.gd` 验证全部110个目的地的天数/费用、长途跨日、失败回滚、保存及线路图按钮状态。战斗房间移动仍按原规则消耗1电量，不使用这一日程规则。
