## 本次结果

- 基地删除右侧详情和展开按钮，八个短标签入口移到底部。装修为独立页面/控制器，合成作为子窗口，完成装修才恢复基地导航。

- 设施前F显示左侧独立立绘和底部半透明字幕，相关行动置于字幕内；移除居中通用对话框。
- 四种家具仍消耗实际仓库材料；装修卡片按库存启用，合成/放置/回收即时更新，真实鼠标流程覆盖完整层级。
- 敌人使用可见像素轮廓中心作镜像中心；贴图绘制与碰撞共用位置，原生渲染回归检查引擎翻转语义。两种动物保持直立，仅左右翻转。

- Boss清场后出现独立楼梯与返程终端，分别靠近按F下层或返基地；移除合并出口窗口。覆盖清场/距离/暂停/按键重复和电量不足限制；返程时场景切换不会继续访问已脱离树的输入节点。
- 主动道具右侧上下显示生命/电量条；删除整次探索防护倒计时，抗辐射片改为回血和短时护盾。
- 小地图仅揭示已探索房间及真实连通的邻居；同种子房间数扩大1.5倍，原电量预算、主干深度和坐标范围保留，奖励四向、Boss三向连通。
