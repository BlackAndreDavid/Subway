# 区域产出与风险回报 v1

本阶段在像素 PNG 素材与主地图验证通过后单独实施。玩法分区是探索主题；现实经济数据只作区域级参考，不代表一个站点或站外每家企业的实际库存。核战辐射、地下客流和价格全为游戏值。

缺失指标或尚未核实地区用 **0.35 设计基准**，不会补造地区数值。全市社零 16600.93 亿元只记录为背景参考，不分摊冒称单站数据。站点所属参考、分区、局部设计系数均在 `regions.json` 中明确。

工业指数为 `sqrt(区工业值 / 13878.95)`，商业指数为 `sqrt(区社零 / 2827.99)`；分区按工业/商业倾向加权，再乘局部设计系数，截断到 `[0,1]`，形成经济参考指数 E。局部系数与分区标签是设计决定，不是统计数据。辐射 R 为 `[1,5]` 的虚构灾后风险级别；基于经济强度与区域探索主题指定，初始邮电新村固定低风险。

## 正相关保证

- 丰富度：`1 + 0.65×(R−1) + 0.30×E`。
- 普通房产生掉落的概率：`0.60 + 0.06×(R−1) + 0.04×E`。
- 额外一份掉落概率：`0.10×(R−1) + 0.12×E`。
- 高阶/专属判定概率：`0.04 + 0.035×(R−1) + 0.025×E`。
- 宝箱总价值预算：`floor((22 + 层数×18) × 丰富度)`，实际物品总价不超预算。
- 电量和电卡拾取价值分别按 `5×丰富度`、`8×丰富度` 四舍五入。
- 防护时间：`360−20×R` 秒，沿用原有风险机制。

辐射每级增量大于经济指数全范围的影响，因此较高辐射区域的丰富度即使跨站比较也更高。高风险不是“必出稀有物”，而是提高概率、数量与预算。测试检查所有站点对的风险带单调性，以及固定种子下大样本平均收益。

## 区域差异与专属白名单

| 区域主题 | 常见物资倾向 | 独占回收材料 | 代表站点 |
| --- | --- | --- | --- |
| 居民生活 | 水、食品、常用药 | 无 | 邮电新村、四平路 |
| 商业中心 | 食品、药物 | 古董机械怀表 | 人民广场、南京东路、陆家嘴 |
| 工业制造 | 电池、武器、模块 | 特种合金锭 | 上海汽车城、闵行开发区 |
| 电子科创 | 电芯、模块 | 封装半导体晶圆 | 张江高科、广兰路、漕河泾开发区 |
| 生物医药 | 药物、医疗模块 | 密封培养试剂 | 张江路、周浦 |
| 交通物流 | 电池、装备 | 精密涡轮轴承 | 虹桥火车站、浦东机场 |
| 港区装备 | 电池、模块 | 航运阀组件 | 港城路、滴水湖 |
| 郊野农业 | 水、食品 | 耐储种子包 | 惠南、航头、西岑 |
| 文旅文教 | 食品、医药 | 修复历史档案 | 豫园、朱家角、复旦大学 |

常见物资权重按区域不同。专属物资在其他区域的产出概率严格为 **0**；普通房、Boss 额外掉落、宝箱均使用同一白名单。基地市场仍可销售从其他区域带回的物资，这是跑商行为，不视作本地生产。固定奖励和战斗补给商仍是常规模块/药物。

八种专属材料同样遵循 PNG 工作流：两张文生图候选与提示词已保存，视觉选择 A 后做功能切片，新增运行图标，不复用不相符的旧图标。

## 再生成与测试

```sh
python3 tools/apply_balance.py --data-only
python3 tools/prepare_art_manifest.py
godot --headless --path . --script tools/import_art.gd
python3 tools/simplify_art.py
bash tools/test.sh
```

`loot_rules.gd` 集中处理产出；`regional_loot_checks.gd` 检查区域白名单、所有专属可达、宝箱预算、全部风险带、收益统计。地图移动电量改用真实主要站点图上的最短通道数：同站 0，其余 `4 + 2×通道数`，不再依赖数组索引。
