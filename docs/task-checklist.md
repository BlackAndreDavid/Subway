# 本轮任务验收清单

范围：用户明确要求的 Godot 游戏开发框架、PNG 动画素材工作流、上海地铁主地图、风险回报与区域差异、中位数颜色精简，以及后续UI/战斗交互/地面掉落修正。附件中的联机、执照、黑市等远期构想未纳入本轮；见 `design.md`。长期内容扩展和真人长线平衡不冒称已完成。

## 框架

- [x] GitHub 项目、Godot 4.6 配置、主界面开始/设置/退出。
- [x] 三份独立存档、创建/读取、基地命名、空名称默认上海堡垒、保存与损坏档案拒绝。
- [x] 2.5D 基地与家具网格放置/拖动/回收、防重叠、地图、探索、开店、下一天资源消耗。
- [x] 坦克/射手/刺客的生命、容量、护甲和射程差异；模块/主动武器/有限次数药物。
- [x] 四向移动动画、普通射击、主动效果、四类小怪与 Boss。
- [x] 每层20–30房间，树状扩展、中段奖励收束、末端Boss、局部链接、无掉落至少80%覆盖的电量路线。
- [x] 奖励、商店、普通房随机掉落、宝箱预算、跨层与返程结算。
- [x] 背包占格、战斗锁定、非战斗交换/装配/卸下/丢弃，药物捡回不重置次数。
- [x] 六类商品各四种、站点交易价差、顾客买卖、库存与每日刷新。

实现：`scripts/game.gd`、`main.gd`、`catalog.gd`、`combat.gd`、`floor_generator.gd`、`world_view.gd`。验证：`tests/test_runner.gd`，包括1000个地图种子与交互流程。
